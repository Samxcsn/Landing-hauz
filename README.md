# Hauz Negócios Imobiliários — Landing Page

Landing page responsiva criada para prospecção, sem anúncios ou imóveis fictícios.

## Como abrir
Basta abrir `index.html` no navegador.

## Como funciona a conversão
O formulário de "simulação / atendimento" não inventa imóveis nem precisa de banco de dados para a primeira versão. Ao enviar, ele monta uma mensagem com os dados preenchidos e abre o WhatsApp da imobiliária.
